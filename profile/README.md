# AELYXORA

### Imagine. Design. Engineer.

**Architecture-first. AI-driven. Built for systems and hardware.**

We are building **AELYXORA Studio** — an open-source, AI-native engineering environment centered on an **interactive Project Architecture Map and contextual AI chat**.

**Humans design the architecture. AI implements the components. Engineers stay in control.**

## A Different Way to Engineer Software

Rather than organizing development around forms or source files, AELYXORA organizes the whole project as a **typed, interactive architecture graph** — combining the intuitive navigation of mind maps with the precision of UML-inspired component contracts.

- **Architecture Map** — modules, interfaces, components, devices, dependencies and data flow in one connected workspace.
- **AI Component Engineer** — select a node or subsystem, provide explicit context, generate implementation proposals and inspect graph/source diffs before approval.
- **Hardware-first Thinking** — CPU/ISA, ABI, drivers, memory, buses, registers, interrupts, DMA and protocols represented when relevant.
- **Assembly-first** — a native low-level implementation strategy with LLVM/Clang tooling and target-specific platform adapters.
- **Own Declarative UI** — an in-house UI language and runtime, not a dependency on Qt/QML, FMX or Slint.
- **Verifiable Engineering** — clear ownership, tests, build evidence and human-approved architectural changes.

## How It Will Work

**Map the system → Define contracts → Ask AI to implement → Review changes → Build and verify.**

The architecture map is the primary workspace. Code, UI, hardware inspectors, diagnostics and tests are detail views of the same project graph.

## Our Flagship Project

**[AELYXORA Studio](https://github.com/AELYXORA/Studio)** — architecture-centric development for software close to hardware.

The intended AI experience includes officially supported ChatGPT authorization where available. **ChatGPT Plus is not automatically a general API credential**; this integration is not yet implemented.

## Current Status

**Experimental foundation, not a usable IDE release.** The initial code is a small Linux x86-64 Assembly UI-tree validator with local tests. The architecture map, AI chat, renderers and cross-target runtime are still planned.

We develop openly and prioritize honest progress, reviewable engineering and concise, useful documentation. Automated CI is intentionally disabled until release preparation.
