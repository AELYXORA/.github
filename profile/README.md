# AELYXORA

### Imagine. Design. Engineer.

**The next generation of visual application development.**

AELYXORA is an open-source initiative building a professional, AI-native Rapid Application Development platform.

Our flagship project, **AELYXORA Studio**, reimagines the productivity of Delphi and WinDev for modern software engineering — combining visual application design, architecture-driven development, AI-assisted implementation, and full control over source code.

## Our Vision

Software development should combine the speed of visual construction with the precision, transparency, and flexibility of professional engineering.

**Design visually. Build intelligently. Own your code.**

## AELYXORA Studio

A unified development environment envisioned around six complementary capabilities:

- **Visual Application Designer** — Compose interfaces, layouts, forms, and reusable components.
- **Architecture Designer** — Define modules, interfaces, dependencies, and architectural contracts.
- **Data & Logic Designer** — Model structured data, business operations, events, and data bindings.
- **AI Architect** — Design, generate, modify, and refine applications with AI assistance.
- **Professional Code Editor** — Work directly with source code, build tools, debuggers, and tests.
- **Cross-Platform Development** — Target desktop, mobile, server, and systems software through an extensible platform architecture.

## Architecture First

At the heart of AELYXORA is a planned unified, typed **Application Model**.

This model describes application components, properties, events, actions, interfaces, data flows, and architectural constraints. Visual tools, AI agents, and conventional programming workflows will operate around this shared model.

Our guiding principles:

1. Architecture is an active part of development, not just documentation.
2. AI assists engineering decisions but never replaces deterministic validation.
3. Generated source code remains readable and maintainable.
4. Visual development and manual programming coexist.
5. Applications remain independent of the IDE wherever practical.
6. Open standards, extensibility, and reproducible builds matter from the beginning.

## Technology Direction

The initial direction is:

- **C++ and Qt 6.12 / QML** for IDE and visual tooling
- **Typed Application Model** for component and architecture contracts
- **CMake and native toolchains** for builds
- **Language Server Protocol** for code intelligence
- **AI integration** for architecture-aware generation and controlled changes
- **Cross-platform runtimes**, starting with Qt-based applications

Long-term targets include extensible language backends, native application generation, and low-level systems development.

## Roadmap

**Phase 1 — Foundation:** Application Model, component contracts, project format, architecture specifications.

**Phase 2 — IDE Core:** Project management, visual designer, property inspector, code editing, build integration.

**Phase 3 — AI-Native Development:** Architecture-aware AI workflows, change validation, generated implementations, automated testing.

**Phase 4 — Application Platform:** Data modeling, reusable components, cross-platform deployment, SDK, ecosystem expansion.

## Project Status

**Early architecture and foundation planning.** Features and technology decisions described here are goals, not claims of completed implementation.

## Open Development

AELYXORA aims to develop in the open, with public technical documentation, architectural decisions, implementation progress, and clear quality standards.
