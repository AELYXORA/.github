# AELYXORA — Brand Guidelines

**Brand:** AELYXORA. **Product:** AELYXORA Studio. **Tagline:** Imagine. Design. Engineer.

## Visual identity

The radiant architectural A, central star, and orbit lines communicate precision, component relationships, and discovery. The SVGs are practical vector adaptations of the concept artwork, not pixel-exact extractions.

## Assets and usage

- `assets/brand/avatar.svg`: organization avatar source. Export to PNG for GitHub Settings.
- `assets/brand/avatar-round.svg`: social avatar.
- `assets/brand/symbol.svg`: stand-alone star symbol.
- `assets/brand/logo-horizontal.svg`: horizontal wordmark.
- `assets/brand/banner.svg`: GitHub profile banner.
- `assets/brand/icon-monochrome.svg`: one-color use.

Preserve icon proportions and clear space; never stretch or rotate. Prefer high-contrast dark backgrounds. Use the mono icon for small contexts. The downloadable Brand Starter Pack contains ready-to-upload PNG exports.

## GitHub organization avatar

Open https://github.com/organizations/AELYXORA/settings/profile and upload `avatar.png` from the downloadable brand pack. Profile README and its SVG banner are managed in this repository.
